Connect automatic backups to your own Drive or computer

Guide · 24 November 2026

The app's API Endpoint setting (Pro) sends a backup to an address you choose. These two free templates give you that address, running on your own Google account or your own computer. We never see your backups and hold no key to them.

Not technical? The simple Google Drive guide (export, or a backup folder plus a sync app) needs no setup like this.

A. Straight into your Google Drive (Google Apps Script)

About 10 minutes, on a computer. A small script runs in your Google account and saves each backup as a file in a Drive folder called "Eisenhower Matrix backups". It keeps the newest 30 for each phone.

  1. On a computer, go to script.google.com, signed in to the Google account whose Drive you want to use, and click New project.
  2. Delete what's in the editor, then copy in the whole template script.
  3. Near the top, change CHANGE-ME-to-a-long-random-word to your own secret: at least 20 letters, numbers, - or _, for example tea-garden-Lamp-7319-river. Click Save.
  4. Click Deploy → New deployment, pick the type Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  5. Google asks you to authorise the script. Because it's your own script, Google shows "Google hasn't verified this app": click Advanced → Go to (your project), then Allow. This lets your script use your Drive; it doesn't give anyone else access.
  6. Copy the Web app URL. It ends in /exec.
  7. In the app, open Settings → Backup & Sync. Tap API Endpoint to open its fields and enter the Web app URL, then /, then your secret:
    https://script.google.com/macros/s/AKfy…/exec/tea-garden-Lamp-7319-river
  8. Leave API key (optional) empty (Google refuses that header on script addresses; your secret in the address does that job). Tap Save, then Backup Now.
  9. Check your Drive: the folder "Eisenhower Matrix backups" now holds a .json file. Turn on Auto Backup if you want it every few hours.
Keep the address private

Anyone who has the full address, secret included, could send or read backups. Don't share it. To change it, edit the secret, choose Deploy → Manage deployments → Edit → New version, and update the address in the app.

B. To a folder on your own computer (small server)

For people comfortable with a command line. A one-file Python program saves each backup in a folder on your computer. Point it at your Google Drive for desktop folder (or Dropbox, OneDrive…) and the backups land in that cloud drive too. Your computer has to be on when the phone backs up.

  1. Install Python 3 if you don't have it, and download backup_server.py.
  2. Make up a key of at least 20 characters, then run (with your own key and folder):
    python3 backup_server.py --key tea-garden-Lamp-7319-river --folder "G:\My Drive\Eisenhower backups"
    On Windows type python instead of python3 if needed. It listens on your computer only, at port 8787.
  3. The app only talks to https:// addresses, so give the server one. Two free ways:
    • Tailscale (private, stays the same): install Tailscale on the computer and on your phone, signed in to the same account, then run tailscale serve --bg 8787. It prints an address like https://my-pc.tail1234.ts.net. Only your own devices can reach it.
    • Cloudflare quick tunnel (fast to try): run cloudflared tunnel --url http://localhost:8787 and use the https://….trycloudflare.com address it prints. It changes every time you start it, so it's best for trying things out.
  4. In the app, open Settings → Backup & Sync. Tap API Endpoint, enter that https address, and enter your key as API key (optional). Tap Save, then Test Connection and Backup Now. The server window prints Saved ….

The server keeps the newest 30 backups for each phone and refuses any request without your key.

Restoring

With either template, open Settings → Backup & Sync and tap Restore from Backup. On a new phone, enter the same address (and key), put the old phone's backup ID in Restore from another device ID, and restore. The backup files are ordinary JSON, so you can also download one from Drive and use Settings → Data Management → Import Tasks from File.

Who can see what

  • Us (the developer): nothing. The app sends backups straight to the address you entered.
  • Google stores the files in your Drive under your account, as with anything else in your Drive. Tailscale or Cloudflare carry the encrypted connection to your computer if you use them.
