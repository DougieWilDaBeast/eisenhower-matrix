把自動備份連到你自己的雲端硬碟或電腦

使用指南 · 2026 年 11 月 24 日

App 的 API 端點 設定（Pro）會把備份傳送到你指定的網址。下面兩個免費範本就是提供這個網址的方法，分別在你自己的 Google 帳號或你自己的電腦上執行。我們看不到你的備份，也沒有任何存取金鑰。

不熟悉技術嗎？簡易的 Google 雲端硬碟備份指南（匯出檔案，或備份資料夾搭配同步 App）不需要這些設定。

A. 直接存進你的 Google 雲端硬碟（Google Apps Script）

約 10 分鐘，需要使用電腦。一個小指令碼會在你自己的 Google 帳號中執行，把每份備份存成雲端硬碟「Eisenhower Matrix backups」資料夾裡的檔案，每支手機保留最新的 30 份。

  1. 在電腦上，用你想使用其雲端硬碟的 Google 帳號登入 script.google.com，點選 新專案。
  2. 刪除編輯器裡原有的內容，然後貼上完整的 範本指令碼。
  3. 在靠近開頭的地方，把 CHANGE-ME-to-a-long-random-word 改成你自己的密語：至少 20 個英文字母、數字、- 或 _，例如 tea-garden-Lamp-7319-river。點選 儲存。
  4. 點選 部署 → 新增部署作業，類型選 網頁應用程式。設定 執行身分：我、誰可以存取：所有人，然後點選 部署。
  5. Google 會要求你授權這個指令碼。因為這是你自己的指令碼，Google 會顯示「Google 尚未驗證這個應用程式」：請點選 進階 → 前往（你的專案），再點選 允許。這只是讓你的指令碼使用你的雲端硬碟，不會讓其他人取得存取權。
  6. 複製 網頁應用程式網址，結尾是 /exec。
  7. 在 App 中開啟 設定 → 備份與同步，點選 API 端點 展開欄位，輸入網頁應用程式網址，加上 /，再加上你的密語：
    https://script.google.com/macros/s/AKfy…/exec/tea-garden-Lamp-7319-river
  8. API 金鑰（選填） 請留空（Google 會拒絕送到指令碼網址的金鑰標頭；網址裡的密語就負責這個工作）。點選 儲存，再點選 立即備份。
  9. 查看你的雲端硬碟：「Eisenhower Matrix backups」資料夾裡會出現一個 .json 檔案。如果想每隔幾小時備份一次，請開啟 自動備份。
請保管好這個網址

任何拿到完整網址（包含密語）的人，都可能傳送或讀取備份，所以請不要分享。若要更換，修改密語後選擇 部署 → 管理部署作業 → 編輯 → 新版本，並在 App 中更新網址。

B. 存到你自己電腦上的資料夾（小型伺服器）

適合會使用命令列的人。一個單一檔案的 Python 程式會把每份備份存到電腦上的資料夾。把它指向 電腦版 Google 雲端硬碟 的資料夾（或 Dropbox、OneDrive 等），備份也會一併進到那個雲端空間。手機備份時，電腦需要開著。

  1. 如果還沒有 Python 3，請先安裝，然後下載 backup_server.py。
  2. 自己想一組至少 20 個字元的金鑰，然後執行（換成你自己的金鑰和資料夾）：
    python3 backup_server.py --key tea-garden-Lamp-7319-river --folder "G:\My Drive\Eisenhower backups"
    在 Windows 上如有需要，請把 python3 改成 python。它只在你的電腦上監聽 8787 連接埠。
  3. App 只會連到 https:// 開頭的網址，所以需要幫伺服器準備一個。有兩種免費方式：
    • Tailscale（私人且網址固定）：在電腦和手機上都安裝 Tailscale，並登入同一個帳號，然後執行 tailscale serve --bg 8787。它會顯示類似 https://my-pc.tail1234.ts.net 的網址，只有你自己的裝置能連到。
    • Cloudflare 快速通道（最快可以試用）：執行 cloudflared tunnel --url http://localhost:8787，使用它顯示的 https://….trycloudflare.com 網址。每次啟動網址都會改變，比較適合試用。
  4. 在 App 中開啟 設定 → 備份與同步，點選 API 端點，輸入那個 https 網址，並在 API 金鑰（選填） 輸入你的金鑰。點選 儲存，再點選 測試連線 和 立即備份。伺服器視窗會顯示 Saved …。

伺服器會為每支手機保留最新的 30 份備份，並拒絕沒有正確金鑰的請求。

如何還原

不論使用哪個範本，都是開啟 設定 → 備份與同步，點選 從備份還原。換新手機時，輸入相同的網址（和金鑰），在 從另一台裝置的 ID 還原 填入舊手機的備份 ID，然後還原。備份檔案是一般的 JSON 檔，所以你也可以從雲端硬碟下載其中一份，再用 設定 → 資料管理 → 從檔案匯入任務 匯入。

誰看得到什麼

  • 我們（開發者）：什麼都看不到。App 會把備份直接傳到你輸入的網址。
  • Google 會以你的帳號把檔案存放在你的雲端硬碟，就像你雲端硬碟裡的其他檔案一樣。如果你使用 Tailscale 或 Cloudflare，它們只負責傳送到你電腦的加密連線。
